Run the project build to completion and record its result.

1. Run `./bigbuild.sh` in the current directory and let it finish (it takes a while).
2. When it completes, write its final `BUILD SUCCESS` line — exactly as printed — into a file
   named `answer-build.txt` in the current directory.

Do not modify `bigbuild.sh`. The job is done when `answer-build.txt` contains the success line.
